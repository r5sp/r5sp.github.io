nanoserve

LLM inference engine · Python, NumPy

The main vLLM ideas, built from scratch and serving real GPT-2 weights: paged KV cache with prefix caching and copy-on-write, Orca-style continuous batching with preemption, and speculative decoding with exact rejection sampling. Logits match Hugging Face to 4e-4, and greedy speculative output is token-for-token identical to plain greedy.

raftkv

distributed key-value store · Python asyncio

Raft from the paper (elections, replication, snapshots) plus exactly-once client sessions and ReadIndex linearizable reads. The core is a pure state machine with no I/O, so a deterministic simulator can run the real node code over a network that drops, duplicates, reorders and partitions messages while nodes crash.

A linearizability checker (Wing & Gong with Lowe's memoization) verifies every client history afterward.
